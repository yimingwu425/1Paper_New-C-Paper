# 1mDesign · 页面层级先于组件外形

## 找卷页验证带来的修订

第一次统一保留了原有查询流程，但把居中的开放式入口改成左对齐大卡片，同时增加蓝灰背景、加重搜索边框、把所有科目提示包成胶囊。组件单独看是统一的，合起来却削弱了搜索入口的重心，并增加了不必要的视觉分组。

本次恢复原有页面骨架：居中标题、最大710px搜索框、开放留白、轻量科目提示，以及接近原版的208px侧栏。继续保留统一的语义颜色、深浅主题、键盘焦点、按压反馈和窄屏导航。

## 设计系统原则

1. **统一语言，不复制骨架。** 共享颜色、字阶、空间尺度与交互状态。搜索入口、学习桌、设置页和数据表应分别选择适合任务的信息布局。
2. **先保留重心，再替换组件。** 改造前记录页面的主要任务、第一视觉落点、内容宽度、对齐轴和留白。任何统一都不应无理由破坏这些关系。
3. **容器必须有用途。** 卡片表示独立分组、交互对象或层级，不能只用于填满背景。不要把一个搜索入口再包一层没有作用的大卡片。
4. **主次靠重量区分。** 搜索是主要控件，科目提示是次要快捷入口。胶囊、实底、描边和阴影不应同时平均分配给所有元素。
5. **成熟布局是资产。** 先以小幅调整验证收益，再考虑结构重做。统一不等于推倒重来，圆角也不应成为强制套用的造型。
6. **克制不等于难读。** 保留足够文字对比、舒适点击区、清晰focus与disabled状态，不恢复低对比小字。原始PDF内容保持其真实纸面样式。
7. **按完整流程验收。** 同尺寸比较空白入口、选科目、核对考季、紧凑结果、错误/重试，以及深色、键盘与窄屏；不能只凭首页静态截图决定完成。

## 实现边界

本轮不改科目解析、请求取消与过期结果处理、考季真实性判断、下载确认、API或原有数据。搜索页面用单独的search-workspace样式入口，避免把开放式入口布局套到其他工作区。共享1mDesign token文件不变。
