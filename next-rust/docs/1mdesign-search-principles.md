# 1mDesign · 页面层级与任务中的动效

## 找卷页的设计校准

搜索入口保留居中标题、最大710px搜索框和开放留白。侧栏、顶栏、结果区和其他页面沿用较新版本的工作区设计，不把局部构图偏好扩展为整页回退。

搜索页使用轻柔的蓝色渐层与单一抬高的搜索表面。蓝色承担氛围和视觉记忆，主要信息保持清楚；不再以无用途的大白卡包住整个入口。

## 设计系统原则

1. **统一语言，不复制骨架。** 共用颜色、字阶、空间尺度和交互状态；搜索、学习桌、设置和数据表各有任务布局。
2. **校准修改范围。** 页面中的优秀局部应保留，但不意味着其他组件、背景或导航需要回到同一历史版本。
3. **先保留重心。** 改造前记录任务、第一视觉落点、内容宽度、对齐轴和留白。组件统一不能无理由破坏这些关系。
4. **容器必须有用途。** 卡片表示独立分组、交互对象或层级，不为填满背景而增加。原始PDF内容保持真实纸面样式。
5. **记忆点来自组合。** 蓝色氛围、纸面般的搜索表面和轻柔的科目流动形成页面特征。不要堆叠装饰、徽章或组件展示墙。
6. **动效服从选择。** 科目流动使用单份真实按钮与原生横向滚动，桌面分两行、窄屏分三行，相邻行错向错速、缓慢往返；鼠标悬停、键盘聚焦时暂停，手动滚动或触控后保持暂停，并提供明确的暂停/继续按钮。输入筛选时结果静止。
7. **减少动态必须完整可用。** 系统减少动态模式不启动自动滚动，科目换行完整呈现，所有入口仍可点击和通过键盘操作。选中科目后焦点交给年份输入；响应式重新分行与减少动态切换时保留当前科目的键盘焦点，避免丢失位置。
8. **按完整流程验收。** 验证入口、筛选、选科目、考季核对、紧凑结果、深浅主题、键盘和窄屏。视觉截图不能代替功能回归。

## 实现边界

本轮不改变题源请求、请求取消/过期处理、考季真实性判断、下载确认、API或用户数据。共享1mDesign token不变。仅调整搜索区构图与背景、恢复较新外壳样式、增加科目流动及其无障碍行为。
